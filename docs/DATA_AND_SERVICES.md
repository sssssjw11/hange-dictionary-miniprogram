# 私有词库与本地服务

## 数据目录

```text
server/data/                  # Git 和 Docker 均排除
  dictionary.db              # 可选的 ECDICT / WordNet 补充数据库
  oxford/
    oxford.db                # 自己的 MDX 转换结果，查询时只读
    chinese.db               # 对应源指纹的中文反查索引
    media.db                 # 可选的 MDD 媒体索引，关联同一 MDX 来源指纹
server/models/               # 可选的 Vosk 模型，排除于版本控制
server/runtime/              # 本地生成的语音文件，排除于版本控制
server/.optional-python/     # 可选私有依赖目录，排除于版本控制
output/                      # 离线分卷、测试报告、布局投影，全部排除
```

服务也接受 `--data-dir` 或 `HANGE_DICT_DATA_DIR`。原本地工作区可自动复用相邻 `../output/` 的已有数据；克隆 GitHub 仓库不会取得私有数据库。

## 微信完整离线包

将原始 MDX 逐条转换，保留所有正文和跳转；离线包对相同正文去重，建立分块随机访问索引、前缀联想及中文单字、双字索引。单数据文件小于 48 MiB，当前完整数据解压约 130.2 MiB。三份 ZIP 分别解压到同一个暂存目录，核对所有大小及 SHA-256 后才提交。

本地用户文件与缓存文件的总额受微信容量限制。当前官方文档为 200 MB；本项目把词库生成预算限制在 180 MiB，实际包约 130.2 MiB。学习数据每类最多 2 MiB，使用两个文件槽轮换提交；导出的备份也会占用用户文件空间。空间不足时导入或写入会明确报错，请先把备份保存到自行选择的位置并整理空间。

完整分卷只在本地交付。在词库管理中可分次添加索引卷和所有数据卷，选齐后再开始导入；不要混用不同构建版本。合并的大 ZIP 供电脑留存，手机优先选择三个较小分卷。更新时先在应用中移除旧词库；生词、笔记、历史和学习进度独立保存。

微信在导入过程中退出时，重新导入会清理仅属于本应用词库的未完成暂存目录，避免重复占用空间；不会清理学习文件。页面关闭后再次进入，也能查看当前进程内继续执行的导入进度。

## 从配套服务传输完整词库

“词库管理 → 从配套服务导入”提供本地分卷传输入口。先移除需要更新的旧文字包，再点击该入口；设备使用阅读与服务设置中的地址，获取同一批索引卷与数据卷。现有手动选文件方式继续可用。服务默认只监听电脑本机；手机访问时需使用可访问的局域网或 HTTPS 地址，正式小程序仍需自己的 AppID 和合法域名配置。

新版 `build_offline_pack.py` 为带有效 MDX 来源指纹的构建自动生成 `output/offline-pack-transfer.json`。已有分卷可以单独登记，无需重打包：

```powershell
python scripts/prepare_pack_transfer.py "output/牛津十版-微信离线词库-索引.zip" "output/牛津十版-微信离线词库-数据1.zip" "output/牛津十版-微信离线词库-数据2.zip"
python server/app.py --host 0.0.0.0 --pack-dir output
```

分卷与传输索引须在同一目录，最多 5 卷、每卷最多 64 MiB。服务通过 `--pack-dir` 或 `HANGE_OFFLINE_PACK_DIR` 选择该目录，默认 `output/`；只提供索引登记的 ZIP，不接受客户端指定电脑路径。若服务装有牛津数据库，则要求分卷与其 MDX 来源指纹一致。分卷更新后需重新登记；客户端沿用本次构建 ID，版本变化会中断本次下载并提示重试。

客户端每次只保留当前下载卷，核对卷大小及 SHA-256 后检查 ZIP 路径与本地文件头，再解压并删除该下载临时文件。全部分卷齐全、清单指纹一致、所有解压文件大小与 SHA-256 通过后，才提交离线词库。手动与服务导入共用提交路径，并阻止重叠任务；失败清理本次暂存目录，学习文件保持独立。实际可用空间仍受微信本地存储限制。若下载中断，可从入口重新开始；未实现断点续传。

传输索引和分卷均属于私有交付材料，不进入公开仓库。当前电脑已登记现有 3 卷，总下载大小 123,064,077 字节，解压文件总大小 136,509,804 字节；没有重新生成词库内容。真实微信全量网络传输及手机运行尚未验收。

v2.3 在摘要索引上增加了单字和完整可见正文索引：优先选取最多四条中文释义，保留完整正文；旧包仍能查词，历史及复习摘要会使用新版提取逻辑。联想和反查建议使用本次同批完整分卷，更新前先移除旧包。

中文反查基于中文释义、用法及例句找相应英文词条，优先排列中文释义直接命中的结果。它不是独立的汉英出版社词典，也不执行机器翻译。新版完整离线反查支持单个汉字和中文短语，每页显示 40 项，支持前后翻页直至全部结果。同一词头按统一大小写去重；候选还要经过完整正文确认。检索也包含原文中没有 `chn` 标签的中文，英汉混合输入统一大小写，补充平面汉字按完整码点处理。旧包缺少单字索引时会提示更新，不把“索引不支持”误报成“词典没有这个字”。服务器安装 `chinese.db` 后也可只依靠牛津数据库反查，不要求补充词库。

打开中文反查结果时，小程序尝试在对应牛津正文中定位输入的词句；如果结果来自补充词典或原文无法可靠定位，会显示提示并保留完整词条。词条中的“词条内查找”也可主动搜索最多 256 个 UTF-16 单元的英文、中文或短语，通过底部按钮切换匹配位置；查找不改动正文、目录和未保存笔记。查询采用大小写、常见空白、撇号和 Unicode 组合字符归一化；遇到无法可靠映射的特殊字符时不会猜测位置。返回全文可退出定位。

结果页与词条页之间仅在当前小程序进程中暂存查询上下文，使用与选中词头绑定的一次性短标识，五分钟内有效，最多暂存 16 条，随进程退出清除；日常页面跳转不把长查询放进地址或学习备份。主动分享关联词时，分享路径包含短语和关联词，以便接收方再次查找。此功能使用已加载正文，不要求重新导入牛津分卷或升级配套接口。

OPAL 词表短语优先查询自身词条；不存在时尝试打开该条原始记录指定的关联词，并在实际显示的牛津正文中查找完整短语。学术词表链接中的原始锚点属于另一套学术词典，不能直接作为高阶正文位置；找不到完整短语时明确提示并保留关联词全文。词表的“相关词”和无独立释义复习卡也沿用此行为；原始词条缺失且关联词也未找到时保留原查询建议。短期跳转上下文与查询词绑定、一次使用，不写入学习备份；已有文字分卷无需重新导入。

v2.4 直接兼容已安装的 v2.3 分卷，无需重新生成或导入。原词库、正文和中文索引不变；分页读取只保留两次检索的候选 id 和每次最近三页，避免把完整匹配列表持续送到视图。服务端使用 `GET /api/reverse` 返回后续页；应用会沿用 `nextCursor`，不自行假定它是页码。关联表达每组显示 24 个，服务端保留全部关联目标。服务端也为最近两次检索缓存正文是否命中的布尔值，连续翻页时不重复解析已经确认的正文；每次请求结束即关闭数据库连接。

## 多词典对照与缓存

牛津正文保留表格、表头、行和单元格结构，设置固定表宽与单元格换行；没有合并单元格的表格会补齐缺少的尾部空格，长表尽可能按完整行分段，避免原来把每个单元格排成独立文字。只读取有效的行列合并数字，不执行源脚本或样式。原始文字、关联词及学习记录不因此改变。已安装的文字分卷无需重装；旧缓存中有旧表格时可选择“更新表格”，更新需要可用的新版服务或完整分卷，并核对已有来源指纹、保留草稿和阅读状态。

所提供词库的表格未检测到跨行、跨列合并；其他词库中跨分段的纵向合并单元格尚未验收。单行本身极长时仍可能被拆分；本次扫描的源表最长一行约 1.9 KB。微信模拟器及手机上的实际表格样式、窄屏显示仍需验收。

牛津正文下方的“本页关联词”按原文链接位置显示当前页内有文字的关联表达，每组最多 8 个，可继续翻组；定位到原文某处后仍按可见页显示关联词。点击跨词条链接会打开新的词条页，返回时保留原页尚未保存的笔记；同词条内的有效义项链接仍可直接定位。原始目标的入口标记只有在目标词头匹配、目标 ID 唯一时才定位到入口，否则明确提示未提供具体定位。

已安装文字分卷会按需生成本页关联位置，不需重装。旧缓存可点击“读取本页关联”，从已安装分卷或新版词库服务取得位置；仅在词头及已有来源指纹匹配时更新，并保留最新阅读页、查找状态和未保存的笔记。旧服务未提供位置时保留下方完整的“关联查词”列表，不伪造链接位置；部分原始链接指向现有 MDX 不含的搭配词典目标，仍会显示未找到。

牛津正文和双语例句提供“点词查释义”面板，读取当前内容页的文字并按最多 1,200 个 UTF-16 单元分段。点击英文单词或汉字可查看摘要、打开完整词条或加入生词本；开启“选择词句”后可依次点击起点、终点，跨面板分段选取最多 256 个 UTF-16 单元的词句并查询。面板以简化段落展示，原富文本正文与定位不变；返回原词条时保留尚未保存的笔记。打开面板及选择文字不会改写词库、学习记录或查词历史。

在词条页点“更多词典”后，应用向已配置的服务查询当前原词头的 ECDICT、WordNet 和原创说明；不会重新传输牛津正文，也不自动连接模型服务。读取成功后可切换“英语分义”“开源简释”等标签，牛津当前页及未保存笔记继续保留。

已读补充内容与整条查询缓存共用 4 MB / 30 项预算，使用单独命名空间，不会覆盖同名单词缓存；清理缓存不删除学习记录。安装词库后可直接合并已有补充缓存，刷新并关闭应用网络服务后仍可查阅。服务失败时保留已有补充与正文；无补充库、未收录以及连接失败分别显示实际状态。`running` 等独立词条按自身词头匹配，不套用 `run` 的动词分义。

## 原版录音与插图（MDD）

词条原文中的录音、例句音频及插图引用保留在 `oxford.mediaRefs`，不执行源脚本。客户端从“录音与插图”进入独立原生页面，每页 12 项，可按类型及原文语境搜索。旧缓存缺少这些信息时，会尝试从新版服务重新读取；父词条页的笔记不随媒体页更新。已有牛津文字分卷无需重新导入。

当前提供的原始目录只有 MDX、CSS、JS 和封面，没有 MDD。完整原版媒体必须由用户另行提供；页面会区分未导入、词库版本不匹配、具体资源缺失和连接失败。系统合成朗读仍保留在词条页，以“朗读”标识。

MDD 通过可选的 [mdict-utils](https://github.com/liuyug/mdict-utils) 读取，在配套服务所在电脑执行：

```powershell
python -m pip install mdict-utils==1.3.14
python scripts/import_mdd.py ".\自己的词库\oald10.mdd" ".\自己的词库\oald10.1.mdd"
```

只提供实际存在的分卷。默认关联 `server/data/oxford/oxford.db`，生成新的 `server/data/oxford/media.db`；已有数据库或 `.partial` 文件不会覆盖。也可通过 `--dictionary`、`--output`、`--reader-dir` 指定自己的输入或读取器。服务会在下次查询发现已完成的媒体导入，不必重装微信文字词库。

导入支持 PNG/JPEG/GIF/WebP 和 MP3/WAV/M4A/AAC，每个资源最多 16 MiB，并检查文件头。脚本、样式、未知格式、非法路径和不符合格式的内容不导入，数量会计入 `unsupported`；跨分卷相同资源去重，不同内容的同名资源会使导入失败。资源键只作为数据库键，不按 MDD 路径释放到电脑目录。媒体必须与该数据库记录的 MDX 指纹匹配，错误版本不会播放。

原版媒体按需从配套服务下载；客户端最多暂存 4 个文件、共 16 MiB，离开媒体页停止音频，关闭页面释放这些临时文件。它们不属于已安装的完整离线文字分卷，也不包含在学习备份中。手机使用配套服务时仍需可访问的服务地址；正式环境需自己的 HTTPS 配置。真实微信图片预览及音频播放仍需真机验收。

v2.12 的词条发音、复习发音及连续播放共用音源选择逻辑。`mediaVersion: 2` 仅为原文音标区中带明确发音标题的录音添加 `pronunciationText`；按标准化后的原词形和所选口音匹配，不从文件名猜测，也不将例句音频当成词头发音。同一词形有多个匹配时按源顺序查询，候选分批读取，每批最多 24 项。

v2.19 另从牛津词表的每条原始记录读取明确标注英式或美式的录音链接，提供逐项朗读，并供该词表导入后的复习与连续播放使用。链接与词库来源指纹一起核验；当词表自身包含对应录音时优先使用该记录，不按文件名猜词形。词表内容可从现有文字分卷读取，无需重新导入；仅使用配套服务时需升级服务以提供词表的录音链接和来源指纹。真实录音仍需另行导入对应 MDD。没有独立释义的短语在复习时可朗读、查看关联词或跳过，不生成释义和答题成绩。

连续播放默认“原版优先”：可用原版录音播放完后推进，缺少或播放失败则明确显示系统合成来源；“系统合成”直接使用本机音色；“仅原版”在缺少录音时暂停，不自动跳词。该选择保存在播放断点及 v3 完整备份，旧备份缺少字段时沿用默认值。释义仍使用系统朗读，并显示实际音色。未导入 MDD 的状态最多短暂复用 30 秒，避免每个词重复查询；切换音源或离开页面后重新读取。

## 每日一句与例句听读

阅读书架中的正文可单页朗读或从当前页连续朗读；每页完整音频结束后才进入下一页，服务或播放失败时停在当前页。再次点击当前朗读按钮可停止；手动翻页、查词、开始标注或离开页面会暂停并丢弃迟到的音频结果，返回时由用户重新开始。沿用页级阅读进度，不保存页内音频时间点，也不在后台持续播放。

阅读正文使用系统合成与设置中的实际音色、口音和语速；含汉字的页面选择中文，其他页面选择英文，中英混合页仍按整页选择音色。每页正文不超过现有 1,800 字分页预算，未截断为较短朗读。音频播放结束、停止或失败时释放本次合成下载的临时文件；取消后迟到的下载也会清理。MDD 原版文件继续由原版媒体管理器独立管理，不由合成朗读删除。真实微信音频事件、窄屏操作及听感仍待验收。

每日一句和每日听力优先从当前可用的牛津 5000 词表中按日期选词，最多检查 12 个候选，选择带中文译文、长度合适的完整例句；同一天同一词库默认得到同一句，“换一句”可继续浏览。没有可用牛津词库、读取失败或候选中没有合适例句时，使用原创学习例句并标明来源。词表和例句优先从已安装的离线包读取；也可通过已配置的本地词库服务读取，选择过程不会加入查词历史。

词条的“双语例句”页可逐句朗读。每日练习与词条例句按当前音源和口音设置，只有原版媒体标签包含完整例句且口音一致时才使用对应录音；标签被截断或未匹配时不会猜测资源。原版优先在缺少录音时使用系统合成，系统合成直接朗读，仅原版则提示缺失；页面显示实际音源，停止、翻页或离开页面会取消未完成的播放。现有词库没有 MDD，实际原版例句录音仍需用户另行导入。

例句可以收藏为本地卡片；重复收藏相同原文和译文会保留卡片已有笔记和来源，主动编辑仍可修改或清空笔记。新增功能不要求重新导入文字分卷。

旧缓存可以在用户点击发音时按需获取新元数据，不重置父词条笔记或复习记录；更新结果要求匹配原词头及已有的来源指纹。播放期间切换词条、跳过词卡、暂停、返回或进入后台会取消延迟播放；页面隐藏时释放该页音频临时文件。点击当前正在发音的英式/美式按钮可停止。

## 每日跟读录音

每日一句与每日听力页可先听原句，再点击“开始跟读”调用微信麦克风，点击结束后回听自己的录音。录音与回听不请求配套服务或模型；原句朗读仍使用既有原版 / 合成音源设置。录音期间禁用原句播放，开始录音会停止尚未完成的原句发音，回听与原句播放互相停止；重录失败时保留上一份可用录音。

本地跟读通过共享录音管理器录制最多 60 秒的 MP3，16 kHz、单声道、48 kbit/s；语音输入继续使用服务所需的 WAV 与识别能力检查。麦克风只在用户点击后调用，不自动同意权限。录音期间显示计时，完成后显示原生返回的时长，空文件、无有效时长或超过 2 MiB 的结果拒绝回听并清理。实际格式支持、授权、中断和音频听感需要微信客户端验收。

每页仅保留当前例句的一份临时录音，重录成功才替换；换句、隐藏或卸载页面会停止并清理文件，取消后迟到的录音同样移除。原版 MDD 文件不由跟读清理。录音不写入学习成绩，不上传，不进入完整备份；没有原厂评分、排行榜、录音分享或长期录音档案。

## 学习统计与每日明细

“学习 → 学习记录与每日明细”可选择日期，查看提交次数、新学与复习次数、回忆成功率、答题计时及截至该日的 7／30 天趋势。回忆成功率按评分统计：困难、记住、熟练计入成功，忘记不计入；拼写和选义结果使用其实际提交评分。计时沿用词卡提交时的用时，每次最多计 600 秒；跳过、单纯朗读和查看页面不产生答题记录。日汇总沿用最近 400 个有记录日期的保留规则。

v2.25 起每次提交同时保存词条、评分、练习模式、首次学习标志、完成时间及当地日期、用时和提交标识；最近 2,000 次明细保存在现有学习文件中，仍受该类记录 2 MiB 总预算限制。按每页 25 条查看，可筛选全部、需巩固（忘记 / 困难）、新学和复习，并打开完整词条。原有日期没有明细或明细已因容量规则移除时显示提示，不根据当前词卡倒推历史，也不虚构逐词结果。

v3 完整备份包含明细，旧 v2 / v3 未含明细的备份仍可导入。合并沿用当前日期汇总优先：该日期的明细同样保留当前值，避免把另一份记录拼入而超过汇总；只补入当前没有的日期并按提交标识去重，最后保留最近 2,000 条。导入校验日期、评分、模式、重复标识和明细计数不超出日汇总，失败不替换已提交数据。统计为本地替代，不读取原厂云端答题历史；新页面的微信日期选择、窄屏与图表滚动待验收。

## 阅读全文查找

导入书架后的 TXT、EPUB 或含文本 PDF 正文可离线查找，无需配套服务。单篇沿用 200,000 个 UTF-16 单元的正文上限，查询最多 256 个单元；忽略大小写、合并空白与下划线，并匹配规范等价的组合重音字符及弯引号。可跨阅读分页查找，保留重叠匹配；“上一处 / 下一处”遍历全部结果，当前匹配用边框和下划线提示，原批注颜色保留。

匹配位置保存为页面控制器内部的紧凑数组，最大约 1.6 MB；不把整份结果传入原生视图，也不写入学习记录或备份。跳转沿用阅读页进度，关闭后留在当前位置；正文被替换或移除时清除旧位置，快速切换后不执行过期滚动。进入查找或执行新查询会暂停朗读。功能作用于导入后的文字，不包含源 PDF 页面坐标、扫描图像检索或 DRM 解密；微信客户端滚动、软键盘及底部安全区仍待验收。

## 分组、批注与备份

生词本最多 30 个，单词可属于多个生词本，每次最多批量整理 500 词。删除分组仅移除归属，保留单词、笔记及全局复习进度。分组可直接选作复习或连续播放的词表；单组导出的 Android 兼容 JSON 为平面词条，完整结构由完整备份保存。

阅读页可长按文字写批注，或依次点选起止位置进行跨页高亮；每次范围最多 6000 字符，每篇最多 1000 条标记。书签和批注目录可搜索并回到原文。批注保存在导入后的正文上，随本项目完整备份恢复，不写回源 PDF/EPUB 文件或原厂批注格式。

完整备份导出为 v3，最大 14 MiB，覆盖六类各 2 MiB 的本地记录与生词本。仍可导入 v2 完整备份和旧 Android 生词本 JSON。合并同一材料的批注时要求正文一致；相同 ID 的当前笔记和阅读进度优先保留，新增标记补入。若正文不同、范围非法、分组引用丢失、空间不足或提交失败，则不替换已提交数据。

## OCR、语音与 PDF

基础安装只需要 `server/requirements.txt`。完整可选服务可在自己的 Python 虚拟环境安装：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r server/requirements.txt -r server/requirements-media.txt
.venv\Scripts\python.exe scripts/setup_speech_models.py
.venv\Scripts\python.exe server/app.py
```

已有解释器也可把可选依赖安装到私有目录；服务会识别该目录：

```powershell
python -m pip install --target server/.optional-python -r server/requirements-media.txt
```

| 能力 | 实现 | 输入范围与实际限制 |
| --- | --- | --- |
| OCR | RapidOCR + ONNX Runtime，服务器本地推理 | 图像最多 8 MiB、20 MP；服务器缩放至 2400 边长后识别，结果需核对 |
| 语音识别 | Vosk small EN-US 0.15 / CN 0.22 + FFmpeg | WAV、最多 10 MiB、60 秒；中英识别链路已实测；不是云识别或长录音字幕服务 |
| 朗读 | Windows System.Speech / SAPI，必要时 FFmpeg 转 MP3 | 每次 1～2500 字；实际音色由系统安装情况决定；Linux 默认不可用 |
| PDF | PyMuPDF | 含文本 PDF，最多 10 MiB、200 页；不支持加密或直接提取扫描页文字 |
| EPUB | ZIP/OPF/spine 顺序解析，保留正文 | 最大 10 MiB、解压内容 40 MiB、总正文 80 万字；不运行书内脚本，不处理 DRM |
| 本机阅读 | 微信用户文件 | 单篇最多 20 万字、100 篇；长书按章节导入，正文数据达到 2 MiB 会提示容量不足 |

Windows 上模型所在目录如果含中文，服务先尝试短路径，再使用仅指向所选模型的任务临时目录联接；不会移动原始模型。也可自行设置英文模型根目录：`HANGE_VOSK_MODEL_ROOT`。

Vosk 模型来自 [官方模型清单](https://alphacephei.com/vosk/models)；OCR 实现参考 [RapidOCR 官方项目](https://github.com/RapidAI/RapidOCR)。本仓库不附带权重。当前本地工作区已安装中英 Vosk 模型和可用 OCR，但这些依赖不随公开源码上传。

连续播放位于“学习 → 单词连续播放”，支持顺序、循环、释义朗读和断点位置。音频结束后才推进；切换页面或进入后台暂停，不把播放计作完成复习。原生图片编辑/裁剪位于拍照页面，使用微信 [editImage](https://developers.weixin.qq.com/miniprogram/dev/api/media/image/wx.editImage.html) / [cropImage](https://developers.weixin.qq.com/miniprogram/dev/api/media/image/wx.cropImage.html)。客户端不支持接口时会显示错误，不上传未经用户确认识别的图片。

设置页的“发音与朗读”提供默认音源、默认英文口音和慢速/标准/快速三档合成语速。三档向当前 SAPI 服务发送相对语速 `-2 / 0 / 2`，不表示固定倍速，也不改变原版录音速度。试听使用原创短句及当前实际音色，生成或下载中离开页面会取消后续播放，缺少所选口音时显示实际音色。

默认值适用于没有显式选项的发音调用；词条和复习页的英美按钮保留各自明确的口音，连续播放已有断点中的音源和口音优先。英文阅读、例句和每日听力采用默认口音，合成释义也采用统一语速。旧设置缺少字段时使用原版优先、美式、标准；非法偏好不提交，读取历史异常值时使用默认值。设备偏好保存在当前微信设置，学习备份中的播放断点仍保留各自选择。

“读取音色”刷新配套服务已安装且启用的 Windows SAPI 音色；连接服务成功时也会读取列表。当前英文口音和中文各有选择器，英式、美式和中文分别保存，初始均为“自动选择”。列表保留实际名称与语言区域；选择其他口音的音色时，播放状态显示其实际口音。音色仅在保存它的服务地址生效，改用其他服务时不传旧音色名；在新服务选择后替换当前绑定。保存的音色若已不在列表中仍显示原选择，实际发音报错，用户可刷新或改回自动。试听使用当前英文音色，中文选择用于中文释义等朗读；原版录音不受合成音色选择影响。

## AI / 全文翻译：当前待配置

客户端没有模型密钥输入框；密钥只放在配套服务的环境中。没有配置时 `/api/assistant` 返回明确的 HTTP 503，页面禁用发送，不提供预设“AI 答案”或假译文。

| 服务端环境变量 | 用途 |
| --- | --- |
| `HANGE_AI_BASE_URL` | 自行提供的兼容模型接口根地址，包含需要的 `/v1` 等前缀 |
| `HANGE_AI_MODEL` | 实际模型名称 |
| `HANGE_AI_API_KEY` | 可选，只存服务端，不能提交到 Git |
| `HANGE_AI_MAX_TOKENS` | 输出上限，默认 2048；达到上限时页面显示未完整结束 |

适配器请求 `POST {BASE_URL}/chat/completions`，支持学习问答、词句讲解、写作批改、阅读摘要与全文翻译；单次最多 20 条消息、总输入 16000 字符。输入点击发送后才传给已配置模型。当前没有模型服务，调用真实提供方的结果、中文长文本质量和长输出完整性尚未验收。

## 本地 API

| 方法 / 路径 | 用途 |
| --- | --- |
| `GET /api/health` | 词库、版本及中文索引状态 |
| `GET /api/suggest?q=` | 前缀联想 |
| `GET /api/lookup?q=` | 完整正文、分义、例句、音标、全部关联词；中文多结果含后续游标 |
| `GET /api/wordlists` | 从已导入牛津读取等级、主题、OPAL 词汇分表及短语分类目录 |
| `GET /api/wordlist?id=` | 读取目录中选定词表，保留词性、级别、相关词、明确标注的录音链接及词库来源指纹；客户端分页显示 |
| `GET /api/offline-pack` | 当前私有离线分卷的构建 ID、大小、指纹及可用状态 |
| `GET /api/offline-pack/file?buildId=&volume=` | 仅提供当前构建登记的对应 ZIP，支持字节范围 |
| `GET /api/dictionary-media/status` | 对应词库的 MDD 导入状态与媒体数量 |
| `POST /api/dictionary-media/resolve` | 按词库来源指纹查询一页媒体是否可用，每次最多 24 项 |
| `GET /api/dictionary-media/file?key=&sourceSha256=` | 读取已导入的图片或录音，支持字节范围；不接受任意电脑文件路径 |
| `GET /api/supplement?q=` | 当前原词头的简释、词形、WordNet 和原创说明；不含牛津正文 |
| `GET /api/reverse?q=&cursor=` | 中文反查每页 40 条；返回 `nextCursor`，为 `null` 表示结束 |
| `GET /api/capabilities` | OCR / TTS / ASR / AI / 翻译 / 文档的真实可用性 |
| `GET /api/voices?refresh=1` | 已启用音色的实际名称与语言区域；`refresh=1` 重新枚举安装列表 |
| `POST /api/tts` | JSON 合成请求，含 `text`、`variant`、`language`、`rate` 及可选的已安装音色名 `voice`；返回实际 `voice`、`locale`、`voiceExplicit` 与 `variantFallback` |
| `GET /api/audio/{name}` | 生成的音频，支持 Range |
| `POST /api/ocr`、`/api/asr` | multipart 的 `file`；语音可携带 `language` |
| `POST /api/document` | multipart 的 `file` 和 `filename`，提取用户文档 |
| `POST /api/assistant` | JSON 模型请求，未配置则 503 |

服务默认只绑定本机地址。日志不记录查询词、正文或输入消息；不会自动接收生词笔记。局域网监听需显式使用 `--host 0.0.0.0`。Docker 基础镜像只带查询与文本解析，不包含 Windows 语音、模型或私有数据；使用自己的挂载与 HTTPS 配置后再用于其他设备。
