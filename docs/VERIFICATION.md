| 布局投影 | 23 页 × 320/390/768/1024 宽度 × 浅/深主题，另含选图、文件、分组选择、阅读标注、反查分页、关联表达、补充词典及目录/定位/源目标缺失等状态，共 328 组 Chromium 投影，无横向溢出或控制台错误；不能替代微信布局引擎 |
| 公开文件 | 发布前扫描 Git 跟踪文件；词库、APK、签名、模型、用户记录和密钥排除；Docker 上下文同时排除这些私有目录 |

详细私有数据报告位于本地 `output/`，不进入公开仓库：`full-corpus-verification.json`、`source-navigation-audit.json`、`native-offline-verification.json`、`content-verification.json`、`client-verification.json`、`media-verification.json`、`layout-verification.json`、`native-runtime-verification.json`。83 项 JavaScript 与 17 项 Python 测试在本地启用私有数据及真实媒体服务后通过；公开 CI 缺少这些私有资源时会明确跳过对应项。
