## v2.9 牛津词表补充记录

源词库中的等级、主题、OPAL 记录已接入词表页与学习导入。提供的文件解析为 555 个可浏览词表/分表入口；客户端读取代码与服务端目录 ID 一致。核心列表按 `data-ox3000`、`data-ox5000` 筛选，OPAL 按原有词汇分表和短语分类筛选，保留词性、级别及相关词链接。

在现有离线分卷的模拟文件系统读取与真实本地数据库读取中，抽取五种词表的结果一致：牛津3000为 3,799 条记录 / 2,977 个去重词条，牛津5000为 5,903 / 4,951，OPAL 书面语分表1为 121 / 100，OPAL 口语短语为 249 / 249，Animals A1 为 11 / 11。这些是所提供文件的实际数量。

本次仅执行四项词表专项及官方模板编译：覆盖来源筛选、带逗号短语导入、重复导入保留进度、原生页面控制器的有限分页、引用链接及缺少独立释义时的原文播放。没有重跑全套、整库正文或模拟器流程，未验收真机。词库分卷及已有学习记录格式保持兼容。

## v2.8 学习标记补充记录

新增 `learning` 元数据：`cefr`、`ox3000`、`ox5000` 与对应 `fk` 字段分别记录。仅读取源属性，正文文本与定位编号保持原有转换路径；目录标签跟随当前义项，词条标签汇总各份正文。

本次只运行新增 JavaScript 专项、Python 字段读取检查和 23 页官方模板编译，均通过。没有扩大到整库重跑、完整回归或新增微信模拟器流程；本节不继承这些范围的成功结论。未提供标签的旧缓存仍可阅读，重新从新版服务获取后才包含新元数据。

## v2.7 拼写建议补充记录

已实现词头、词形别名的相近拼写推荐，保留原查询并通过独立页面打开所选词条；内部数字消歧别名不作为推荐项展示。最终词形扩展后，8 项离线包检查及 3 项 Python 专项通过，包含真实完整分卷、`recieving → receiving → receive` 和 `housess → houses → house`。建议来自实际词库入口，完整词条读取仍优先使用原有精确索引。

开发过程中完整运行过 90 项 JavaScript、20 项 Python 检查（含真实本地服务及媒体），该轮早于最后的词形别名扩展；最终扩展未重跑全套。新增拼写建议、空结果及长查询的布局状态后，344 组 Chromium 投影通过。新交互尚未完成微信模拟器及真机验收。

以下完整正文、目录、补充词典及原生运行记录保留 v2.6 及此前版本的证据范围。本次没有修改正文转换器或词库分卷。

## 复现命令

```powershell
npm ci --ignore-scripts
npm run build:codec
npm run build:data
npm run check
npm test
python -m unittest discover -s tests -p 'test_*.py' -v

# 启动本地服务后，在另一终端启用真实查询联调
$env:HANGE_TEST_API='http://127.0.0.1:18748'
npm test

# 已安装可选引擎和模型时
$env:HANGE_TEST_MEDIA='1'
python tests/test_features.py

# 已生成自己的离线包时，逐份核对全部正文
node scripts/verify_offline_corpus.js
node scripts/verify_chinese_index.js
```

公开 CI 会跳过没有私有词库、没有模型的联调项，但仍运行通用存储、转换、输入契约、分页和模板检查。不会把跳过项计作真机成功。
