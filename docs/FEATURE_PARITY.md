# 原 APK 功能对照

参考对象为用户提供的欧路词典 Android APK：`com.eusoft.eudic`，26.10.0，versionCode 34436。依据其 Android 清单中的活动与资源功能标识核对功能族；未绕过原服务账号，也未完成原 APK 的全流程运行对比。下表是实际交付范围，不代表原应用全部隐藏入口已验收。

当前目标是免登录的微信本地开发版。用户明确要求移除账号与不必要模块，并确认暂时没有 AppID、HTTPS 或模型服务；AI 与翻译保留待配置。

| 主导航 `MainTabActivity` | 词典、AI、生词笔记、学习、我的五项原生 Tab，共 23 页 | 已实现；23 页浅/深主题模拟器运行通过，真机待验收 |
| 英文、短语、中文、历史查词 `HistoryRecordActivity` | 完整正文分页、输入联想、词形跳转、中文反查、最近 100 条记录 | 已实现；真实离线查询与分页通过，单字与短语每页 40 项、可遍历全部匹配并去重；返回保留页码及滚动位置；词形跳转显示原词头与输入来源 |

## 后续验收所需条件

本机已使用微信开发工具提供的测试号进入模拟器，23 页浅/深主题、完整词库安装、真实离线查词、长词条分页、中文反查、本地文件记录与 v3 备份合并导入已运行。公开配置继续保留占位值。当前没有自己的正式 AppID、HTTPS 或模型服务；真机的文件分享、录音、相机、裁剪、音频、系统主题和实际机型仍待验收，详见 [开发工具与运行验收](WECHAT_DEVTOOLS.md)。

要补齐表中的原厂云内容、商业题库、MDD 或在线接口，需要相应实际资源与可用接口。原厂后台和 Android 系统行为不能仅凭 APK 清单转换成微信服务。任何后续资源接入仍应保留应用免登录、本地学习记录和明确服务状态。
