# 原 APK 功能对照

参考对象为用户提供的欧路词典 Android APK：`com.eusoft.eudic`，26.10.0，versionCode 34436。依据其 Android 清单中的活动与资源功能标识核对功能族；未绕过原服务账号，也未完成原 APK 的全流程运行对比。下表是实际交付范围，不代表原应用全部隐藏入口已验收。

当前目标是免登录的微信本地开发版。用户明确要求移除账号与不必要模块，并确认暂时没有 AppID、HTTPS 或模型服务；AI 与翻译保留待配置。

| 原应用功能族 / 参考活动 | 微信开发版行为 | 状态及限制 |
| --- | --- | --- |
| 主导航 `MainTabActivity` | 词典、AI、生词笔记、学习、我的五项原生 Tab，共 19 页 | 已实现；微信运行验收待完成 |
| 英文、短语、中文、历史查词 `HistoryRecordActivity` | 完整正文分页、输入联想、词形跳转、中文反查、最近 100 条记录 | 已实现；中文反查每次最多 40 项 |
| 本地词库安装 `InstallDictActivity` | 私有 MDX 转换、完整牛津分卷导入、逐文件 SHA-256 校验、移除 | 已实现牛津十版格式；未实现任意 MDD 媒体词典管理 |
| 富文本释义 `HtmlViewActivity` | 原文自定义标签转为微信富文本；全部文字可分页访问，双语例句可收藏 | 整库文字保留核对通过；源脚本不执行 |
| 多词典与词形 | 牛津正文、英英分义、开源补充释义和原创学习说明分别显示 | 服务支持本地 ECDICT / WordNet；完整补充库不装入手机代码包 |

| 拍照识词 / 裁剪 `CropActivity` | 用户拍照或选图，RapidOCR 识别，编辑文字后查词 | OCR 已联调；未提供独立裁剪编辑器 |

| 生词、笔记 `DictNoteMngActivity` | 收藏、笔记、搜索、分页、导入导出 | 已实现；当前只有一个生词本，额外分类可用自定义词表 |
| 多词表 `ReciteMultiBookActivity` / `ReciteWordListActivity` | 内置词表、生词本、自定义 TXT/CSV/TSV 词表、TXT 导出 | 已实现；每表最多 10,000 词、最多 30 个自定义词表 |
| 复习、计划、统计 `ReciteSettingActivity` / `ReciteStatsActivity` | 间隔复习、每日计划、回忆、拼写、选义、断点继续、七天统计 | 已实现；使用本项目调度算法，不复刻原算法 |

| 单词播放 `WordCardPlayActivity` | 词卡与手动朗读 | 部分；未实现原版自动连续播放、播放皮肤与车机控制 |

| 备份 / 同步 `OnlineSyncActivity` | 完整 JSON 备份、合并恢复，保留当前笔记和进度 | 本地备份已实现；按需求不提供账号云同步 |
| 账号、注册、支付 `RegActivity` / `WXPayEntryActivity` | 不包含 | 按用户要求移除；不需要应用账号 |

## 后续验收所需条件

当前没有可用 AppID、正式域名或模型服务，因此仍需在微信开发工具和真机验证导入、文件分享、录音、相机、音频与系统主题。微信开发工具 2.02.2609240 的命令行服务端口在本机处于关闭状态，本次未修改其安全设置。

要补齐表中的原厂云内容、商业题库、MDD 或在线接口，需要相应实际资源与可用接口。原厂后台和 Android 系统行为不能仅凭 APK 清单转换成微信服务。任何后续资源接入仍应保留应用免登录、本地学习记录和明确服务状态。
