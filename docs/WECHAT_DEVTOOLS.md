## 打开本地项目

1. 在微信开发者工具导入仓库根目录，读取 `project.config.json`；客户端目录为 `miniprogram/`。
2. 用户手动完成开发工具扫码登录。没有自己的 AppID 时，在导入界面选择工具提供的“测试号”，使用其自动显示的项目身份。不要填写其他项目的 AppID。
3. 仅在本地保存该身份；公开仓库和源码 ZIP 保留占位配置。解码库及原生学习数据 JS 已包含，无需“构建 npm”。
4. 在“我的 → 词库管理”添加自己的索引和数据 ZIP。开发工具的文件选择可能每次只返回一个文件，因此可以连续添加三次，确认待选列表后点“开始导入”。
5. 本机 HTTP 服务调试需要在自己本地工程的设置中允许相应网络调试。公开配置保留域名校验；手机不能通过电脑的 `127.0.0.1` 连接服务。

本地测试号不表示已经具备真机预览、上传或发布条件。需要这些能力时再使用自己的有效 AppID、可访问服务和合法域名。

## 官方 CLI

工具已登录、项目身份可用后，可以用以下命令查看运行状态；不上传代码：

```powershell
$dictionaryProject = (Get-Location).Path
wechatide -c codex check_wechatide_status --skill-version 0.3.11
wechatide -c codex open_project_window --project $dictionaryProject --window-mode liteMode
wechatide -c codex automation_runtime_info --project $dictionaryProject --action currentPage
```

当前版本的 `automation_evaluate` 使用 `--fn-source` 或函数文件来源，参数使用 `--args-file`；旧的 `--args` 被 CLI 拒绝。界面导航与截图使用官方 automation / simulator 工具。任务返回需要人工处理时查询原 taskId，避免重复创建授权或登录任务。
