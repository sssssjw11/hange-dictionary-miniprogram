# 涵词典 · 微信小程序

原生微信小程序本地开发版，23 个页面、5 个 Tab。提供完整牛津文字查词、中文反查、词形跳转、学习复习、生词笔记、阅读书架、例句卡片和完整备份。配套本地服务提供真实 OCR、朗读及中英语音转写。

v2.7 增加离线拼写建议：查不到英文单词或短语时，从已有牛津词头、词形和别名中推荐相近入口；点击建议后打开完整原文，返回可继续查看原查询。支持漏字、多字、替换及相邻字母交换，现有分卷继续可用。建议最多 8 项，较短输入使用更小的差异范围。

v2.6 的“牛津目录”继续支持按义项、主题、习语、词组和补充框定位，并保留原编号及关联链接的具体义项。界面延续原 APP 蓝白风格及深色主题。中文反查、关联表达和正文均可完整分页访问；补充 ECDICT、WordNet 及原创说明可按需读取和缓存。AI 和全文翻译按需求待配置；真机及原厂云内容范围见 [功能对照](docs/FEATURE_PARITY.md)。

整库逐份核对保留全部可见文字、664,841 个源定位标记、207,287 个含义项片段的关联目标及 113,606 个义项目录；394,485 个不同定位位置的正文切分均无丢字。源词库自身缺失的具体定位会提示并保留完整词条；目录不执行原网页脚本，也不补造缺失正文。详细范围见 [验收记录](docs/VERIFICATION.md)。

无需应用账号，不含登录、支付、广告或推送。相机、麦克风和文件选择只在用户点击对应功能时调用。学习记录留在本机；识图、转写及模型任务会把用户选定的输入发送到自行配置的配套服务。

## 本地运行

1. 用微信开发者工具导入本仓库根目录，识别 `project.config.json`，客户端目录为 `miniprogram/`。生成后的解码库已包含在源码中，无需“构建 npm”。
2. 仓库默认 `touristappid` 是公开占位值。本机已通过开发工具提供的“测试号”进入模拟器：先由用户扫码登录，在导入界面选择工具提供的测试号，再把工具显示的 AppID 保存到自己的本地配置。这个本地测试配置不随源码分发；真机、上传及发布仍需自己的可用 AppID。详见 [开发工具与运行验收](docs/WECHAT_DEVTOOLS.md)。
3. 在“我的 → 词库管理”导入自己生成的完整牛津离线分卷。未导入时仍有 97 个开源或原创内置词条、195 条词形索引。
4. 如需识图、语音或配套查询，启动本地服务，在“我的 → 阅读与服务设置”保存地址并检查连接。

```powershell
python -m pip install -r server/requirements.txt
python server/app.py
# 或 Windows：.\start-local.ps1
```

默认服务地址为 `http://127.0.0.1:18748`。开发工具调试本机 HTTP 时需要相应本地网络调试配置；项目公开配置保留域名校验。手机不能用电脑的 `127.0.0.1`：局域网调试可运行 `python server/app.py --host 0.0.0.0`，填写电脑局域网地址。正式使用需自己的 HTTPS 和微信合法域名。

## 导入完整牛津

仓库不包含出版社正文、MDX、MDD 或原 APK。使用自己提供的本地 MDX：

```powershell
python -m pip install mdict-utils==1.3.14
python scripts/import_mdx.py ./my-dictionary/oald10.mdx
python scripts/build_chinese_index.py
python scripts/build_offline_pack.py
```

转换数据库保存在被忽略的 `server/data/oxford/`。手机导入用的文件在 `output/`：

- `牛津十版-微信离线词库-索引.zip`
- `牛津十版-微信离线词库-数据1.zip`
- `牛津十版-微信离线词库-数据2.zip`

在词库管理中添加同批生成的三个 ZIP。可以一次多选，也可以分三次添加；待选列表齐备后点“开始导入”。它们是独立 ZIP 分卷，无需合并。应用逐文件核对 SHA-256，全部成功后才启用；导入失败不修改生词、笔记或学习记录。更换词库前先移除旧词库，以免超出微信用户文件空间。

当前提供的十版 MDX 包含 **69,980 条正文记录、240,108 条跳转记录**。相同正文去重后为 69,963 份；解压后约 130.2 MiB，索引卷约 21.5 MiB，两份数据卷各约 48 MiB。英文、短语、词形联想，以及单字和中文短语反查可在导入后离线使用；中文反查每页显示 40 个匹配，可前后翻页直到全部结果；v2.3 分卷无需重新导入，较早的旧包仍可用，但单字检索需要新版整套分卷。

正文按完整节点分页，不截断释义。历史、联想和复习摘要优先提取真正的中文义项，最多带出四条释义，避免把“语法”等领域标签当作词义；完整义项仍在正文。中文反查优先排列释义直接命中的词条。双语例句另有原生分页和收藏按钮；关联表达通过原生按钮查询，每组 24 个，全部表达可逐组访问；服务端不再截取前 60 个。点击“更多词典”可补充简释与英语分义，随后切换相应词典标签；补充内容来自已配置的本地服务，缓存后可离线重看，不会替换牛津正文。源文件中的脚本和外部媒体不执行。当前提供的资源没有 MDD，因而没有原版音频、插图；Windows 朗读是配套服务生成的合成语音。拍照页面支持先选图、原生编辑/裁剪、再识别；编辑能力以实际微信客户端支持为准。英式音色未安装时会明确提示实际使用的音色。

已有的数据库不会被导入脚本覆盖。重新生成离线包可使用 `--rebuild`，只替换生成器自己的文件。更多服务、依赖和容量说明见 [数据与服务配置](docs/DATA_AND_SERVICES.md)。

## 学习和阅读

- 最多 30 个独立生词本、单词多重归属、每次最多 500 词批量整理、分组复习与播放；个人笔记、最近 100 条查词记录；清理查询缓存不删除学习记录。
- 每日新词与复习计划、间隔复习、词卡回忆、拼写、选义练习、单词连续播放、熟词管理、断点继续和七天统计。
- 自定义 TXT / CSV / TSV 词表，支持引号、短语和表头，每个词表最多 10,000 个词、文件最多 2 MiB；可导出 TXT。
- TXT、EPUB、含文本的 PDF 阅读，按章节导入；点词查义、选中短语查词、跨页范围高亮、批注、书签目录和回到原文，支持保存段落为例句卡片。
- 编辑、搜索、复制双语例句与笔记；每日一句、听力练习和用法知识采用原创内容，不冒充原 APP 的在线栏目。
- 新版 JSON 完整备份（v3，最大 14 MiB）涵盖生词本分组、多重归属、笔记、书架、原文批注、书签、例句、复习与对话记录。合并保留当前同名笔记、相同记录及当前学习进度；文件写入或提交失败不替换已提交的数据。兼容旧版 v2 完整备份及 Android 本地版生词本 JSON；新版分组和批注结构需要 v3 完整备份保留。

采用原生 WXML/WXSS/JS、原生导航、五项自定义 TabBar 和两个原生组件，包含安全区、长词换行、分页、系统/浅色/深色与阅读字号。输入时悬浮底栏隐藏，避免遮挡软键盘。源码主包约 0.80 MiB，牛津数据位于微信用户文件中。实际兼容性仍以对应微信客户端验收为准。

## 检查

Node.js 22+ 与 Python 3.11+：

```sh
npm ci --ignore-scripts
npm run build:codec
npm run build:data
npm run check
npm test
python -m unittest discover -s tests -p 'test_*.py' -v
```

有本地私有数据时可执行整库核对：

```sh
node scripts/verify_offline_corpus.js
node scripts/verify_chinese_index.js
```

真实数据与媒体联调的可选环境变量为 `HANGE_TEST_API`、`HANGE_TEST_MEDIA=1`，参见 [验收记录与待验证项](docs/VERIFICATION.md)。公开 CI 不包含私有数据和模型，相关测试会明确跳过。
